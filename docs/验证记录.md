## 权限与剩余边界

新会话默认 `workspace-write`，插件不批准原生权限申请。对演示 Git 根目录补充当前所有者的 `TakeOwnership` 权限，已备份原 ACL；没有递归变更、没有关闭沙箱。

该修复解决了 `SetNamedSecurityInfoW ... grantWrite`，但 `node --test` 在受限沙箱仍出现子进程管道 `spawn EPERM`。真实成功测试来自原生批准/会话切换为 `danger-full-access` 后的执行，不能声称受限沙箱的派生进程问题已解决。

本版仅支持同机双端。关闭 GPT 聊天不会自动唤醒审查；DSH 宿主执行途中重启后会保留 `interrupted` 与仓库锁，需要核对原会话。每轮返工创建新会话，保留旧记录。演示仓库保留在原路径供 DSH 会话与证据引用，不作为产品仓库推送。
